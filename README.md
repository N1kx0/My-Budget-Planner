# 📊 My-Budget-Planner

Ein leichtgewichtiger, interaktiver und 100 % privater Monatsbudget- und Sparplaner für Desktop und Mobile (inkl. voller iOS/Safari-Kompatibilität).

🚀 **Live-Version:** [https://n1kx0.github.io/My-Budget-Planner/](https://n1kx0.github.io/My-Budget-Planner/)

---

## ✨ Features

- **Live-KPIs:** Sofortige Berechnung von Gesamtausgaben, verbleibendem monatlichen Überschuss und freier Sparquote in Echtzeit.
- **Interaktive Schieberegler:** Schnelles Durchspielen von Szenarien mit sofortiger Auswirkung auf das Sparziel.
- **Integrierter Editor-Modus:**
  - Beliebige Kategorien neu anlegen, umbenennen oder löschen.
  - Eigene Farbwahl per Color-Picker für jede Kategorie.
  - Posten hinzufügen, löschen und Regler-Maxima dynamisch anpassen.
- **100 % Offline & Privat:** Sämtliche Daten verbleiben ausschließlich im lokalen Speicher des Browsers (`localStorage`). Es gibt keine Server, kein Tracking und keine Werbe-Skripte.
- **Mobile-First & PWA-ready:** Lässt sich auf iPhone und Android direkt als Web-App („Zum Home-Bildschirm“) ohne Adressleiste installieren.

---

## 📱 Auf dem Smartphone installieren

### iOS (iPhone / iPad)
1. Die Seite in **Safari** öffnen.
2. Unten auf das **Teilen-Symbol** (Viereck mit Pfeil nach oben) tippen.
3. **„Zum Home-Bildschirm“** auswählen.

### Android
1. Die Seite in **Chrome** öffnen.
2. Oben rechts auf das **Drei-Punkte-Menü** tippen.
3. **„App installieren“** oder **„Zum Startbildschirm hinzufügen“** wählen.

---

## 🛠️ Lokale Ausführung

Keine Installation, kein Node.js oder Build-Schritt erforderlich:
1. Repository klonen oder als ZIP herunterladen.
2. `index.html` mit einem beliebigen Browser öffnen.
